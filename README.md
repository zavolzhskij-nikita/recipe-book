# Кулинарная книга

## Описание проекта

Веб-приложение для обмена рецептами. Пользователи могут регистрироваться, добавлять свои рецепты, искать блюда по названию или ингредиентам, а также сохранять понравившиеся рецепты в избранное.

### Стек технологий

| Категория | Технологии |
| :--- | :--- |
| **Back-end** | Python, Django 5 |
| **База данных** | SQLite (встроенная) |
| **Front-end** | HTML5, CSS3 (без сторонних UI-библиотек) |
| **Инструменты** | Git, Figma |

### Реализованный функционал

- Регистрация, авторизация и выход (встроенный Django Auth).
- Добавление рецептов с фотографией (доступно только авторизованным пользователям).
- Поиск рецептов по названию, описанию или ингредиентам.
- Добавление рецептов в избранное и удаление из него (связь `ManyToMany`).
- Личный кабинет (профиль) с отображением своих рецептов и избранного.
- Редактирование своих рецептов.
- 6 основных страниц: главная, каталог, детальная страница рецепта, профиль, форма добавления/редактирования, авторизация.

## Порядок установки и запуска

Для запуска проекта локально выполните следующие команды в терминале:

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/zavolzhskij-nikita/recipe-book.git
cd recipe-book
```

2. **Создайте и активируйте виртуальное окружение:**

```bash
python -m venv venv
```

- Для Windows:

```powershell
venv\Scripts\activate
```

- Для macOS / Linux:

```bash
source venv/bin/activate
```

3. **Установите зависимости и примените миграции:**

```bash
pip install django
python manage.py migrate
```

4. **Запустите сервер разработки:**

```bash
python manage.py runserver
```

5. **Откройте приложение в браузере:** `http://127.0.0.1:8000/`

> **Примечание:** База данных SQLite создаётся автоматически при первом запуске. Для доступа в панель администратора создайте суперпользователя командой:
>
> ```bash
> python manage.py createsuperuser
> ```

## Аналитическая часть

### Целевая аудитория

Сайт создан для домашних кулинаров, которые хотят хранить свои проверенные рецепты в одном месте и делиться ими с другими, не отвлекаясь на рекламу и лишние социальные функции.

### Бизнес-логика

Путь пользователя выстроен максимально просто: **регистрация / авторизация → добавление рецепта с фотографией → поиск нужного блюда → сохранение в личное избранное**. Редактировать или изменять рецепт может только его автор (создатель), что защищает контент от вандализма.

### Аналитика проблемы

Существующие популярные платформы (например, Поварёнок или Say7) перегружены рекламой, сложной навигацией и социальными элементами. Пользователю нужна простая, быстрая и визуально приятная база рецептов, которая отлично работает на мобильных устройствах и не требует лишних кликов.

### Архитектура и аналитика сайта

- **Адаптивность:** Приоритет отдан мобильному трафику (основная аудитория — `375px`). Сайт корректно перестраивается на `960px` (2 колонки), `1200px` (3 колонки) и `1920px+` (ограничение ширины контейнера для удобного чтения).
- **База данных:** Используются 3 основные сущности (`User`, `Recipe`, `Favorite`), что обеспечивает высокую скорость работы и простоту масштабирования. Избранное реализовано через связь `ManyToMany` (одному пользователю — много рецептов).
- **Метрики для отслеживания:** DAU (ежедневная активность), количество созданных рецептов на пользователя, конверсия «просмотр карточки рецепта → добавление в избранное».
